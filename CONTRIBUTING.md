# Contributing

Eden Duo is an independent fork of [Eden](https://git.eden-emu.dev/eden-emu/eden). It is not
affiliated with the Eden project, so please do not take Eden Duo issues, patches or questions to
Eden's trackers, Discord or mailing lists.

- Report bugs and request features in this repository's
  [issue tracker](https://github.com/igawa6/eden-duo/issues).
- Companion packages (the per-game `.dsmod.zip` files), their documentation and their issues
  belong in [Eden Duo Companions](https://github.com/igawa6/eden-duo-companions).
- Pull requests are welcome. New code should follow the style of the surrounding code, and the
  build and tests (`tests '[dsmod]'`) should pass.
- Eden Duo was developed with AI assistance (see the README's "AI Assistance" section). Upstream
  Eden prohibits AI-assisted contributions: do not submit Eden Duo code to upstream Eden.

Eden Duo is free software under the terms of the [GPLv3](LICENSE.txt), the same license as Eden.
By contributing you agree that your contribution is licensed under those terms.
